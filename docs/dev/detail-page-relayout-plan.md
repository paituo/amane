## 二、新布局结构（已实现）

```
┌───────────────────────────────────────────────────────────────┐
│ 番号 · 标题      ★收藏 ▶播放 重新刮削 编辑 📂 ⋯ ✕              │ ← 顶栏
├───────────────┬───────────────────────────────────────────────┤
│               │ [影片信息] [视频信息] [评论]                   │
│  自适应海报     │ 标题(摘要)                                    │
│  ┌─────────┐  │ 制作·发行商·系列·类别·日期·时长·评分·VR         │
│  │  cover  │▶ │ 导演·演员·标签·用户标签                        │
│  └─────────┘  │ 来源链接 · 剧情                                │
│ [剧照画廊 ‹›]  │ ── 影片信息 Tab ──                            │
│               │ 14 项占位（视频信息 Tab，待接口）              │
│               │ ── 评论 Tab ──                                 │
└───────────────┴───────────────────────────────────────────────┘
```

要点：
- 海报列在**左**，自适应高度；下方剧照画廊（主图 + extrafanart），点缩略图切主图，点主图开 `FanartLightbox`。
- 信息列在**右**，三个 Tab；影片信息保留原字段（制作/发行方/系列/类别/日期/时长/评分/VR/导演/演员/标签/用户标签/来源/剧情），标签与演员 chip 仍跳 catalog 页。
- 视频信息 Tab 仅陈列 14 项空字段（时长/编码/分辨率…），附提示「接口接入后显示」——**不读取真实数据**。
- 评论移入第三 Tab（沿用 `CommentSection`）。
- 顶栏集合：收藏、▶播放、重新刮削（下拉：普通/强制）、编辑、在媒体库中打开（有文件时显示）、更多（嵌套：锁定管理 / 合并 / 删除）、关闭。
- 移除原底部「连接文件」卡片与底部操作行。

## 三、Phase 2 后端排期（与 Phase 1 一并规划）

> 这些项需要后端补数据/接口，前端已预留 Tab 与字段位置，落位即填充。

1. **媒体探测接口（视频信息真实数据）**
   - 新增 `GET /api/metadata/{id}/probe`（或 `ffprobe` 服务），返回格式/时长/帧率/码率/分辨率/宽高比/位深度/总帧数/音频格式/音频码率/采样率/声道数/后缀/大小。
   - 前端：视频信息 Tab 的 `VIDEO_INFO_FIELDS` 改为绑定探针结果（loading/error 态）。
2. **字幕列表接口**
   - `GET /api/metadata/{id}/subtitles` → 语言/默认/双语/来源。
   - 前端：影片信息 Tab 内增「字幕」段。
3. **`MetadataResponse` 补字段**：`mosaic`、`original_title`、`publish_number`、`category`、`first_actor`、番号结构（`series_name`/`serial_number`/`first_letter`）。
   - 有码/无码可由 `MediaFileResponse.mosaic` 派生，或后端补到 metadata 层。
4. **演员头像资源接口** `GET /libraries/{id}/actors/{actorId}/photo`（参考已预留 `actor.photo_path`）。
   - 前端：演员 chip 升级为头像横条（无头像用首字兜底）。
5. **用户评分写回** `user_rating` + 可点星。
6. **剧照后端化**：当前 extrafanart 已在前端画廊使用；确认后端 extrafanart 资源 URL 稳定（已由 `FanartStrip` 同款 `proxyImageUrl` 处理）。
