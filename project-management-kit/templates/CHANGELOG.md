# Changelog

> 规则:
> - 新版本节插在最上面 (H1 之后), 标题只写 `## vX.Y.Z`.
> - 分组顺序固定: ✨ 新功能 → 🐛 修复 → ⚡ 性能 → ⚠️ 破坏性变更; 无内容的组不写.
> - `🐛 修复` 只收**已发布版本中存在**的缺陷; 本区间新功能引入的缺陷并入该功能.
> - 同一主题的多条提交合并成一条, 不把每条 commit 摊成一行.
> - 条目写用户能看懂的结果, 不写实现细节、限定条件、迁移边角.
> - Issue / PR 写成 `#13`, 不用链接包裹.
> - 社区贡献在条目末尾追加 `@login` 并带 PR 号.
