# 项目用词规范

> 只登记用词: 顶层概念的两层定名、同一个词在不同位置的义项分工、同一实体的定名取舍.
> 源码里的符号与字段不在此登记, 照现有注释与文案写即可; 遣词造句见 [writing.md](writing.md).
> 用法: 引入新概念、写用户文案、给概念改名时查阅, 不要求通读.

列的含义: 开发中文用于注释、开发文档、提交说明与 PR; 用户中文用于界面文案与用户文档,
不出现实现词 (Agent / SQL / 内部标识符). `—` 表示该层不使用此词.

## 顶层概念

跨模块的一等实体:

| 概念 | 开发中文 | 用户中文 |
|------|---------|---------|
| `<Entity>` | <开发用词> | <用户用词> |
| `<Entity>` | <开发用词> | <用户用词> |
| `<Enum>` / `<EnumValue>` | <开发用词> | <用户用词> |

项目自己的动作, 以及任务类型:

| 动作 | 开发中文 | 用户中文 |
|------|---------|---------|
| `<ACTION>` | <开发用词> | <用户用词> |
| `<ACTION>` | <开发用词> | — |

## 易歧义

同一个词按位置分工, 不得互换:

| 中文词 | 只允许指 | 不允许指 |
|--------|---------|---------|
| 条目 | 列表项、目录项 | 核心实体 (写具体实体名) |
| 类型 | 枚举类型、表单枚举 | 泛指的类别 (必须带限定词) |
| 来源 | 外部数据来源 | 订阅源、日志字段 |
| 站点 | 内置来源 | 插件来源 (写「来源」) |

## 维护

- 新增概念时先在这里定名, 再写代码、文档与文案.
- 改名时同步所有层, 不允许开发中文与用户中文各自演化.
- 同一实体只允许一个用户中文名; 别名写入本表, 不散落在文案里.
